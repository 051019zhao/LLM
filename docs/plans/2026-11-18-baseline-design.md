# 基础仓库设计

目标是让已报名的课程小组尽快完成一次可复现的有效提交，并持续积累报告证据。

采用一个自包含 Kaggle Notebook。它读取比赛目录或本地 `data/` 中的训练和测试文件，先检查必要字段、空值与 ID 唯一性，再用 `GroupKFold` 按 `prompt_id` 做五折验证。特征为词与字符 TF-IDF，分类器为类别平衡的线性 SVM。每一折的特征提取只在训练折拟合，避免验证数据进入词表。验证指标是 Balanced Accuracy，同时输出各类别召回率，便于分析弱类。之后在完整训练集拟合，生成比赛要求的 `submission.parquet`。

Notebook 仅依赖比赛数据和常见 Python 包，能够复制到 Kaggle Code Competition 的 Notebook 中执行。运行前验证输入；输出前检查行数、ID、空值和标签，若不满足要求就明确报错。仓库还提供实验日志、截图清单、课程报告与成绩汇总清单。训练数据、提交文件和个人信息截图默认不纳入 Git。

选择自包含 Notebook，是因为比赛必须通过 Notebook 提交；单纯的命令行训练工程会额外要求上传代码为 Kaggle Dataset。将来有多个方法后，再考虑抽出可复用模块。
